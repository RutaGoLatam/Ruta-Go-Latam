# RutaGo LATAM — GitHub Pages

Sitio estático listo para publicar en GitHub Pages.

## Archivos
- `index.html`
- `styles.css`
- `app.js`
- `assets/`

## Publicar
1. Sube todos los archivos a tu repositorio.
2. En GitHub ve a Settings → Pages.
3. Selecciona la rama `main` y la carpeta `/root`.
4. Guarda y espera la publicación.
