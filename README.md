# RutaGo LATAM
Sitio estático listo para GitHub Pages.

## Incluye
- Selector por país, aplicación y servicio.
- Consulta directa por WhatsApp con país, app y servicio prellenados.
- Experiencia responsive y optimizada para móvil.
- Sección de pagos: Nequi, Bre-B, DaviPlata, PayPal y Payoneer.
- Política de pago 50% para iniciar + 50% al terminar.
- Contacto con asesor para recibir datos/link de pago en tiempo real.

## WhatsApp
El número configurado es +57 323 768 0838. Si deseas cambiarlo, modifica `WHATSAPP_NUMBER` en `app.js`.

## Publicar
Sube todos los archivos y carpetas de este ZIP al repositorio de GitHub Pages.
